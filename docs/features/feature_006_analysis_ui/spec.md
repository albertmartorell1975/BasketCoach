## 1. Source Feature & Idea Diagnosis
* **`id`:** `feature_006_analysis_ui`
* **`area`:** `app`
* **`depends_on`:** `["feature_005_dashboard_ui"]`
* **`status`:** `in_progress`
* **`module_topology`:** `Layer-Based (:domain, :usecases, :data, :app)`
* **Objective:** Implement the high-density Tablet Landscape Analysis screen (`AnalysisScreen`) in `:app` along with the necessary domain model and data DTO expansions. The coach navigates to the Anàlisi screen via the fixed Navigation Rail to view the Phase 1 baseline hero card (consolidated 3V-11D, 21.4%), filter tactical insights via segmented tabs ("Tots", "Fortaleses", "Àrees de Millora"), inspect a responsive 3-column grid of rich tactical strength and improvement cards with empirical metric panels, and trigger the "Explorar al Xat" action intent to the Chat assistant.
* **Identified Ambiguities / Assumptions:**
  1. *Authoritative Phase 1 Baseline*: While the HTML prototype (`docs/ui/screens/analisis_landscape/code.html`) used an illustrative "9V-5D", the authoritative single source of domain truth established in `feature_001`, `feature_002`, `feature_005`, and `docs/general/dataset.json` is **3 Victòries - 11 Derrotes (21.4% de victòries)** over 14 games. The Anàlisi hero card reflects this authentic baseline while adhering to the exact visual structure of `code.html` (left summary block, "Registre Fase 1: 14 / 14 Jornades", and interactive segmented filter tabs).
  2. *Domain Entity Expansion with Backward Compatibility*: In `:domain`, `Insight` is expanded with `InsightType` (`STRENGTH`, `IMPROVEMENT`), `InsightMetric` (empirical metric container with primary metric, primary sub-value, secondary label, secondary value, secondary tag, and `MetricSentiment`), `contextTag`, `priority`, `footerNote`, and `exploreChatPrompt`. To prevent regression in existing tests (`GameModelTest`, `DevExpertApiClientTest`, `AiAnalysisRepositoryImplTest`, `GenerateInsightsUseCaseTest`), default parameter values are provided on the domain entity constructors.
  3. *Data Layer DTO & Prompt Synchronization*: In `:data`, `InsightDto` and `InsightMetricDto` are updated with serialization support. Default values on DTO fields allow existing test fixtures to continue deserializing without error. `AiAnalysisMapper` maps the expanded fields, and `PromptTemplates` is updated to describe the rich metric schema for future AI queries.
  4. *Strict Default-Free & Non-Nullable UI Models (Constraint #17)*: All presentation state models (`AnalysisUiState`, `InsightCardUiModel`, `InsightFilterTab`) have **zero default parameter values** and **zero nullable fields**. The static factory `AnalysisPreviewData` is the sole authoritative source of state during this UI phase (MVVM integration with `GenerateInsightsUseCase` is deferred to `feature_009_analysis_integration`).
  5. *Minimum Font Size Mandate (Constraint #16)*: All UI typography across cards, category pills, empirical metric panels, tags, and footers strictly enforces a minimum font size of `12.sp` (never `10.sp` or `11.sp`).
  6. *Decoupled Composable Architecture*: `AnalysisScreen` (stateful) hosts `AnalysisContent` (stateless). Event callbacks (`onNavigateToChat: (String) -> Unit`, `onFilterSelected: (InsightFilterTab) -> Unit`) are hoisted. Navigation in `Navigation.kt` routes `AnalysisRoute` to `AnalysisScreen`, invoking `appState.navigateToChat()` when "Explorar al Xat" is tapped.
  7. *Bilingual Localization*: Full Catalan (`res/values/strings.xml`) and Spanish (`res/values-es/strings.xml`) parity for all filter tabs, badges, headers, and buttons.
  8. *Graphic Assets Policy*: Mockup `screen.png` remains in `docs/features/feature_006_analysis_ui/ui/screens/` as a reference guide (never converted to drawables). All icons are rendered via standard Jetpack Compose Material Icons.
* **Necessary Questions:** None — all requirements clarified.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide Head Coach Jordi with an actionable, high-density Tablet Landscape tactical analysis screen (`AnalysisScreen`) to diagnose the 14-game Phase 1 competition findings. The coach can filter findings between Strengths and Areas of Improvement, evaluate empirical metric evidence (e.g. 58.4% paint efficiency, 16.2 fast-break points conceded, 42% third-quarter turnovers), and seamlessly transition into the coaching chat with pre-grounded tactical exploration prompts.

### Non-Goals
* ViewModel and dynamic AI analysis generation via `GenerateInsightsUseCase` (deferred to `feature_009_analysis_integration`).
* Full multi-message chat thread UI and AI chat completions (owned by `feature_007_chat_ui` and `feature_010_chat_integration`).
* Phone or portrait layouts (strictly constrained to Tablet Landscape `1280x800dp`).
* Individual player statistical breakdowns (team-level metrics only).

### Job Story
When Coach Jordi navigates to the Anàlisi section on his tablet,
I want to review categorized Phase 1 strengths and tactical vulnerabilities with empirical box-score evidence,
so I can identify priority fixes for Phase 2 and immediately launch the AI assistant to explore specific practice drills.

### Acceptance Scenarios

#### Scenario 1: Tablet Landscape Analysis Screen Rendering & Navigation
* **Given** the app is running on an Android Tablet in Landscape orientation (`1280x800dp`) on the Dashboard.
* **When** the coach taps the "Anàlisi" (or "Análisis") item in `BasketCoachNavRail`.
* **Then** the active navigation rail indicator moves to Anàlisi.
* **And** the viewport renders `AnalysisScreen` displaying:
  1. The Phase 1 Baseline Hero Card with the 3V-11D (21.4%) competitive balance, "Registre Fase 1: 14 / 14 Jornades", and segmented filter tabs ("Tots (5)", "Fortaleses (2)", "Àrees de Millora (3)").
  2. A 3-column responsive grid (`InsightCardGrid`) displaying all 5 authentic tactical cards.

#### Scenario 2: Segmented Filtering (Tots, Fortaleses, Àrees de Millora)
* **Given** the coach is on the Analysis screen with "Tots (5)" selected.
* **When** the coach taps "Fortaleses (2)".
* **Then** the active tab styling moves to "Fortaleses" with a green indicator dot (`#008C45`).
* **And** the grid updates immediately to display only the 2 Strength cards ("Eficiència en Tir Interior", "Protecció de Cistella").
* **When** the coach taps "Àrees de Millora (3)".
* **Then** the active tab styling moves to "Àrees de Millora" with an orange indicator dot (`#F15A24`).
* **And** the grid updates to display only the 3 Improvement cards ("Balanç Defensiu en Transició", "Rebot Defensiu i Punts de 2a Oportunitat", "Gestió de Pèrdues en el 3r Quart").
* **When** the coach taps back on "Tots (5)", all 5 cards are restored without lag or state corruption.

#### Scenario 3: Tactical Strength Card Anatomy & Empirical Metric Panel
* **Given** the coach inspects a Strength card (e.g. "Eficiència en Tir Interior").
* **Then** the card displays:
  1. A subtle green category pill ("Fortalesa Tàctica") with a green dot indicator (`#008C45`).
  2. Context tag on the top right ("Fase Ofensiva · Pintura").
  3. Bold headline ("Eficiència en Tir Interior") and tactical description text.
  4. An empirical metric panel (`PiaSurfaceContainerLow`) showing primary metric ("58.4% efectivitat", "+8.2% sobre mitjana lliga"), benchmark ("1.24 pts/pos"), and dataset tag (`dataset:paint_eff`).
  5. A verified footer note with a green `Verified` icon ("Factor diferencial en 3 de les 3 victòries obtingudes.").
  6. No "Explorar al Xat" button is rendered on Strength cards.

#### Scenario 4: Tactical Improvement Card Anatomy & Tactical Orange Accent
* **Given** the coach inspects an Improvement card (e.g. "Balanç Defensiu en Transició").
* **Then** the card displays:
  1. A Tactical Orange container border (`PiaTacticalOrange.copy(alpha = 0.3f)`).
  2. An orange category pill ("Àrea de Millora") with an orange dot indicator (`#F15A24`).
  3. Context tag on the top right ("Transició · Balanç Defensiu").
  4. Bold headline ("Balanç Defensiu en Transició") and description.
  5. An empirical metric panel showing primary metric ("16.2 pts/partit", "1.31 pts/pos en transició rival" in red), priority level ("Crítica #1"), and dataset tag (`dataset:fastbreak_def`).
  6. A footer with a priority alert icon (`PriorityHigh`) and note ("Pilar corrector Fase 2").
  7. A Navy (`#1D2E54`) action button labeled "Explorar al Xat" with white text and icon.

#### Scenario 5: Actionable Navigation Intent to Chat ('Explorar al Xat')
* **Given** the coach is viewing an Improvement card.
* **When** the coach clicks "Explorar al Xat" on the card.
* **Then** the `onNavigateToChat` callback is triggered with the card's specific `exploreChatPrompt` string.
* **And** the application navigates to the Chat destination (`ChatRoute`), updating the Navigation Rail active selection to Chat.

#### Scenario 6: Domain Model Backward Compatibility & Metric Integrity
* **Given** the expanded `Insight`, `InsightType`, `InsightMetric`, and `MetricSentiment` in `:domain`.
* **When** an `Insight` instance is instantiated using only the legacy 5 constructor parameters.
* **Then** `type` defaults to `InsightType.IMPROVEMENT`, `contextTag` to `""`, `metric` to `null`, `priority` to `""`, `footerNote` to `""`, and `exploreChatPrompt` to `null`, preserving 100% backward compatibility.
* **When** an `Insight` is created with full empirical metrics.
* **Then** all metric labels, values, sub-values, tags, and sentiment values retain their exact values without data loss.

#### Scenario 7: Data DTO Serialization & Mapper Verification
* **Given** an `InsightDto` with full metric data and another with legacy fields.
* **When** deserialized via `Json.decodeFromString<InsightDto>`.
* **Then** both payloads parse successfully without serialization exceptions.
* **And** `AiAnalysisMapper.toDomain()` cleanly maps DTOs into domain models, correctly translating string values to `InsightType` and `MetricSentiment`.

#### Scenario 8: Bilingual Support Verification (Catalan & Spanish)
* **Given** the device locale is set to Spanish (`es_ES` or `es`).
* **When** the coach opens the Analysis screen.
* **Then** all UI elements display Spanish strings from `res/values-es/strings.xml` ("Análisis", "Todos (5)", "Fortalezas (2)", "Áreas de Mejora (3)", "Fortaleza Táctica", "Área de Mejora", "Explorar en el Chat", "REGISTRO FASE 1").
* **When** the locale is set to Catalan (`ca_ES` or `ca`), all strings display in Catalan from `res/values/strings.xml`.
