## 1. Source Feature & Idea Diagnosis
* **`id`:** `feature_005_dashboard_ui`
* **`area`:** `app`
* **`depends_on`:** `[]`
* **`status`:** `in_progress`
* **`module_topology`:** `Layer-Based (:domain, :usecases, :data, :app)`
* **Objective:** Implement the presentation components and two-pane Tablet Landscape Dashboard screen in `:app` for the Junior Men's Interterritorial basketball coach. The dashboard displays the 14 Phase 1 match fixtures and box scores on one pane, and proactive tactical AI insights and recommended practice drills for Phase 2 preparation on the other. It includes Club Esportiu Pia Sabadell branding, Material 3 design tokens, realistic dummy data for tablet landscape Compose previews, and an automated Compose UI test suite.
* **Identified Ambiguities / Assumptions:**
  - *Scope Boundary (UI vs Integration)*: `feature_005_dashboard_ui` focuses strictly on the presentation layer: UI state modeling (`DashboardUiState`), stateless composable architecture, two-pane landscape layout, KPI summaries, game list, insight cards, drill cards, tablet previews, and Robolectric/Compose UI tests with dummy data. Full integration with Hilt and real UseCase interactors (`GetPhase1GamesUseCase`, `GenerateInsightsUseCase`, `GetPracticeDrillsUseCase`) will be implemented under `feature_007_dashboard_integration`.
  - *Strict Tablet Landscape Mandate*: Per `CONSTRAINTS.md`, the UI is exclusively optimized for Android Tablet in Landscape orientation (`w >= 840dp`, e.g., 1280x800dp). Smartphone or portrait-specific layouts are explicitly out of scope. `MainActivity` in `AndroidManifest.xml` will configure `android:screenOrientation="sensorLandscape"`.
  - *Two-Pane Screen Balance*:
    - **Navigation / App Bar**: Displays "BasketCoach", the team identity ("CE Pia Sabadell Junior Blau"), season progress badge ("Phase 1 Analysis • Phase 2 Preparation"), and a primary action button to navigate to the single-thread Chat Assistant ("Ask Coach AI").
    - **Left Pane (~42% width)**: Team record summary banner (3 Wins - 11 Losses), scoring and rebounding averages, scrollable list of 14 Phase 1 matches with W/L status pills and final scores, and an expandable or dedicated box score inspector card for the selected fixture.
    - **Right Pane (~58% width)**: Tabbed or multi-section area with:
      1. Proactive AI Tactical Insights (categorized by `InsightCategory`: `OFFENSE`, `DEFENSE`, `SYNERGY`, `GENERAL`), with related round tags.
      2. Recommended Practice Drills (drill name, focus area tag, objective, and numbered drill instructions).
  - *Visual Identity & Theming*: Colors align with Club Esportiu Pia Sabadell (`Blau` - Royal/Navy Blue `#0D47A1` / `#1565C0` primary, White/Light Slate background `#F8F9FA`, basketball accent Amber/Gold `#FFA000`, Win pill `#2E7D32`, Loss pill `#C62828`).
  - *JVM-Based Compose UI Testing*: To adhere to the canonical gate command (`./gradlew testDebugUnitTest lintDebug`), Robolectric (`org.robolectric:robolectric:4.14.1`) and `androidx.compose.ui:ui-test-junit4` will be added to `app/build.gradle.kts` `testImplementation`, allowing fast, deterministic Compose UI tests to run directly on the JVM in tablet landscape mode without an active emulator.
* **Necessary Questions:** None — all requirements clarified.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide a responsive, high-density Tablet Landscape Dashboard for the Pia Sabadell Junior basketball coach. The interface presents a clear two-pane view connecting the 14 Phase 1 games to proactive AI tactical insights and actionable practice drills, empowering the coach to eliminate past weaknesses and amplify winning strengths for Phase 2.

### Non-Goals
* No live ViewModel-to-UseCase integration or Hilt DI in this feature slice (owned by `feature_007_dashboard_integration`).
* No smartphone or portrait-mode adaptive layouts (strict constraint: Tablet Landscape only).
* No single-thread chat conversation screen or message input (owned by `feature_006_chat_ui`).
* No dynamic game editing or remote database sync (Phase 1 dataset is static).
* No individual player statistics (MVP constraint: team-level metrics only).

### Job Story
When the basketball coach opens the BasketCoach application on a landscape tablet,
I want to view our 14 Phase 1 matches on one pane and tactical AI insights/drills on the other,
so I can quickly review our performance record, inspect specific game box scores, and select practice drills to prepare for Phase 2.

### Acceptance Scenarios

#### Scenario 1: Two-Pane Landscape Layout Renders Both Panes Simultaneously
* **Given** a tablet device in landscape orientation (1280x800dp)
* **When** the `DashboardScreen` is rendered with `DashboardUiState` containing 14 games, 4 insights, and 3 drills
* **Then** the screen renders a horizontal two-pane layout with the Game Fixture Pane on the left and the Insights & Drills Pane on the right
* **And** the Top Bar displays "BasketCoach", the team subtitle, and the "Ask Coach AI" chat navigation action.

#### Scenario 2: Game Fixture List Displays 14 Matches with W/L Badges and Scores
* **Given** the Left Pane rendered with the 14 Phase 1 matches
* **When** inspecting the match list
* **Then** all 14 rounds are displayed in chronological order
* **And** winning matches (e.g., Round 3: 71-68, Round 9: 68-65, Round 10: 67-65) display a green "W" badge
* **And** losing matches display a red "L" badge
* **And** each item indicates home/away venue, date, and opponent name.

#### Scenario 3: Inspect Game Details and Box Score on Match Selection
* **Given** the Dashboard with Round 3 selected
* **When** the user taps on Round 1 match card
* **Then** the `onGameSelected` callback is invoked with the Round 1 `Game` instance
* **And** the selected match highlights visually and displays its box score metrics (rebounds, assists, turnovers, fouls, shooting percentages).

#### Scenario 4: Categorized Tactical AI Insights Display
* **Given** the Right Pane with the "Tactical Insights" section active
* **When** viewing the insights list
* **Then** each insight card displays its category chip (`DEFENSE`, `OFFENSE`, `SYNERGY`, `GENERAL`), title, tactical description, and related match round chips.

#### Scenario 5: Practice Drills with Actionable Steps Display
* **Given** the Right Pane with the "Practice Drills" section active
* **When** viewing the drills list
* **Then** each drill card displays the drill name, focus area tag, objective, and an ordered list of step-by-step instructions.

#### Scenario 6: Trigger Chat Assistant Navigation Callback
* **Given** the Dashboard Top Bar
* **When** the coach taps the "Ask Coach AI" button
* **Then** the `onNavigateToChat` callback is invoked.

#### Scenario 7: Loading and Error State Feedback
* **Given** `DashboardUiState` with `isLoading = true`
* **When** rendered
* **Then** a centered loading indicator is displayed
* **And** when `errorMessage` is present, an error banner with a retry button is shown.
