## 1. Source Feature & Idea Diagnosis
* **`id`:** `feature_005_dashboard_ui`
* **`area`:** `app`
* **`depends_on`:** `["feature_001_domain_models"]`
* **`status`:** `accepted`
* **`module_topology`:** `Layer-Based (:domain, :usecases, :data, :app)`
* **Objective:** Implement the tablet landscape application shell (fixed 80dp Navy Navigation Rail + 64dp White Top Bar with Coach Jordi profile avatar) and the Phase 1 Dashboard screen displaying the baseline hero summary card (3V-11D, 21.4%), 4 KPI metric cards, a 14-round scoring evolution bar chart (with green win badges for J3, J9, J10), and the consolidated 14-match 16-column statistical table. All text must be fully localized in **both Catalan and Spanish** (`res/values/strings.xml` and `res/values-es/strings.xml`).
* **Identified Ambiguities / Assumptions:**
  1. *Strict Scope Boundary*: Zero changes to `:domain`, `:data`, or `:usecases`. All data models in this feature are UI-layer models (`DashboardUiState`, `Phase1SummaryUiModel`, `DashboardKpisUiModel`, `ScoringEvolutionUiModel`, `MatchRowUiModel`) populated by authentic static Phase 1 preview data (`Phase1PreviewData`). ViewModel and real UseCase integration are deferred to `feature_008_dashboard_integration`.
  2. *Interactive Modal Omission*: The Match Inspector Modal (`#match-modal` in HTML prototype) is explicitly omitted per user decision. Table rows and chart bars remain static/selectable without modal popups.
  3. *Graphic Asset Conversion*: `avatar_coach.png` and `basketcoach_logo.png` located in `docs/features/feature_005_dashboard_ui/ui/resources/` MUST be converted into optimized `.webp` format in `app/src/main/res/drawable/` (`ic_avatar_coach.webp`, `ic_basketcoach_logo.webp`) per `DESIGN.md` Section 4. Full-screen sketches under `ui/screens/` MUST NOT be converted to drawables.
  4. *Bilingual Localization*: Full Catalan (`res/values/strings.xml` or `values-ca`) AND Spanish (`res/values-es/strings.xml`) string resources covering all navigation tabs, headers, KPI labels, badges, chart legends, and table columns.
  5. *Pragmatic Testing*: Compose UI tests run headless on the JVM using Robolectric (`NavigationTest` and `DashboardScreenTest`) verifying real layout, semantics, and navigation switching.
* **Necessary Questions:** None — all requirements clarified.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide Head Coach Jordi with a high-density Tablet Landscape dashboard to review the consolidated 14-game Phase 1 competition baseline. The coach can navigate between sections via a fixed Navy Navigation Rail and inspect scoring evolution, key performance indicators, and full box-score statistics in either Catalan or Spanish depending on the device locale.

### Non-Goals
* Dynamic data fetching or ViewModel integration via `GetPhase1GamesUseCase` (deferred to `feature_008_dashboard_integration`).
* Domain/Data model expansion for tactical AI insights (deferred to `feature_006_analysis_ui`).
* Interactive Match Detail modal popup dialog (`#match-modal` omitted per user decision).
* Phone or portrait layouts (strictly tablet landscape `1280x800dp`).
* Dynamic AI chat assistant thread (deferred to `feature_007_chat_ui` and `feature_010_chat_integration`).

### Job Story
When Coach Jordi opens BasketCoach on his tablet during practice preparation,
I want to view the consolidated 14-game Phase 1 baseline balance, KPI averages, scoring chart, and full box-score table in my preferred language (Català or Castellà),
so I can quickly assess team strengths and systemic weaknesses to plan Phase 2 practices.

### Acceptance Scenarios

#### Scenario 1: Tablet Landscape Application Shell Rendering
* **Given** the app launches on an Android Tablet in Landscape orientation (`1280x800dp`).
* **When** the root `BasketCoachApp` composable is displayed.
* **Then** the coach sees:
  1. A fixed `80dp` Navy (`#1D2E54`) `BasketCoachNavRail` on the left displaying destinations: "Dashboard", "Anàlisi" / "Análisis", and "Chat".
  2. A fixed `64dp` White (`#FFFFFF`) `BasketCoachTopBar` with bottom border (`#D1D5DB`/30) displaying "BasketCoach", the category pill ("Junior Masculí Interterritorial" / "Júnior Masculino Interterritorial"), the green verified pill ("Dades consolidades · 14 partits 1a Fase" / "Datos consolidados · 14 partidos 1ª Fase"), and the circular Coach Jordi profile avatar (`36dp`) with labels "Head Coach" / "Jordi".
  3. The main content canvas displaying the Dashboard screen.

#### Scenario 2: Navigation Rail Destination Switching
* **Given** the coach is on the Dashboard screen.
* **When** the coach taps on the "Anàlisi" / "Análisis" item in `BasketCoachNavRail`.
* **Then** the active rail container moves to the selected item and the main viewport displays the clean `PlaceholderScreen`.
* **When** the coach taps on "Chat", the Chat placeholder screen is displayed.
* **When** the coach taps back on "Dashboard", the full Dashboard content is restored without state loss.

#### Scenario 3: Baseline Phase 1 Hero Card Display
* **Given** the coach is viewing the Dashboard screen.
* **When** inspecting the `DashboardHeroCard`.
* **Then** the coach sees:
  - Header badge: `"LÍNIA BASE FASE 1"` (ES: `"LÍNEA BASE FASE 1"`) and verified tag (`"dataset.json verificat · 14/14 partits"` / ES: `"dataset.json verificado · 14/14 partidos"`).
  - Headline: `"Balanç Competitiu: 3 Victòries - 11 Derrotes (3V - 11D)"` (ES: `"Balance Competitivo: 3 Victorias - 11 Derrotas (3V - 11D)"`).
  - Subtitle: red pill `"21.4% victòries"` (ES: `"21.4% victorias"`), `"Junior Masculí Interterritorial"` (ES: `"Júnior Masculino Interterritorial"`), and `"CEB Escola Pia Sabadell"`.
  - Right summary block: `"BALANÇ FASE 1 / 3 Victòries / 11 Derrotes"` (ES: `"BALANCE FASE 1 / 3 Victorias / 11 Derrotas"`) and square `"14 PARTITS"` badge (ES: `"14 PARTIDOS"`).

#### Scenario 4: 4 Key Performance Indicator (KPI) Cards
* **Given** the coach is viewing the Dashboard screen.
* **When** inspecting `KpiCardRow`.
* **Then** exactly 4 cards are rendered horizontally in a row:
  1. *Anotació Mitjana / Anotación Media*: `"64.6"` vs `"73.7 ppg rival"`, red badge `"-9.1 Diferencial net"` (ES: `"-9.1 Diferencial neto"`), `"14 partits"` (ES: `"14 partidos"`), red progress bar at 47%.

  3. *Eficiència Tir (eFG%) / Eficiencia Tiro (eFG%)*: `"40.5%"` `global Fase 1`, 3 mini-boxes (`2P 43.4%`, `3P 25.4%`, `TL 56.4%`), Navy progress bar at 40.5%.

#### Scenario 5: 14-Round Scoring Evolution Bar Chart
* **Given** the coach scrolls to the evolution chart section.
* **When** inspecting the 14 competition rounds (`J1` to `J14`).
* **Then** winning rounds `J3` (71-68), `J9` (68-65), and `J10` (67-65) render the Pia Sabadell bar in Success Green (`#008C45`) with a floating `"W <score>"` badge and green bold X-axis labels (`J3 (V)`, `J9 (V)`, `J10 (V)`).
* **And** all 11 losing rounds render the Pia bar in Primary Navy (`#1D2E54`) and the Rival bar in Slate (`#CBD5E1`).
* **And** the legend displays: "Victòria Pia (W)" / "Victoria Pia (V)", "Pia Sabadell", "Rival".

#### Scenario 6: Consolidated 14-Match 16-Column Statistical Table
* **Given** the coach inspects the match table section.
* **When** viewing the consolidated games.
* **Then** all 14 Phase 1 matches (`J1` to `J14`) are rendered in order with 16 statistical columns (`JORNADA`, `PARTIT`/`PARTIDO`, `MARCADOR`, `EFG%`, `2P%`, `3P%`, `TL%`, `REB (O/D)`, `AST`, `TO`, `AST/TO`, `ROB`/`REC`, `TAP`, `PF`, `2A OPCIÓ`/`2ª OPCIÓN`, `C. ATAC`/`C. ATAQUE`).
* **And** winning rows (`J3`, `J9`, `J10`) display a subtle green row tint and green score badge (`#E8F5E9` bg, `#008C45` text); losing rows display a red score badge (`#FFEBEE` bg, `#D32F2F` text).
* **And** home/away perspective formats CEB Pia Sabadell in bold.

#### Scenario 7: Bilingual Support Verification
* **Given** the device locale is set to Spanish (`es_ES` or `es`).
* **When** the coach opens BasketCoach.
* **Then** all UI elements display the corresponding Spanish strings from `res/values-es/strings.xml` without missing keys or hardcoded Catalan fallbacks.
* **When** the device locale is set to Catalan (`ca_ES` or `ca`), all strings display in Catalan from `res/values/strings.xml`.
