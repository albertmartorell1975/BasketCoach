* **Objective:** Comprehensive re-alignment of the BasketCoach tablet interface to strictly follow the design sketches in `docs/ui/screens/analisis_landscape/` and `docs/ui/screens/dashboard_vertical/`. Implement the fixed Navy Navigation Rail (80dp, `#1D2E54`), White Top Bar with Coach Jordi avatar and status badges, the **Dashboard screen** (Hero baseline card, 4 KPI cards with metrics/progress, 14-round W/L Bar Chart, and 14-match consolidated statistical table), and the **Anàlisi screen** (Hero baseline card, segmented filter tabs Tots/Fortaleses/Millores, and 3-column scrollable grid of rich insight cards with one-click "Explorar al Xat" action). Expand `:domain` and `:data` with structured insight metrics, and purge practice drills from the presentation layer (`:app`).
* **Identified Ambiguities / Assumptions:**
  - *Data Record Correction*: Sketch `analisis_landscape` erroneously printed 9V–5D (64.3%). The real dataset and `dashboard_vertical` establish the true record: **3 Victòries - 11 Derrotes (21.4% de victòries)**. This verified record is rendered consistently across both screens.
  - *Language*: 100% Catalan in `res/values/strings.xml` and preview data, aligned with CEB Escola Pia Sabadell team language.
  - *Drills Removal*: Drills are removed from presentation (`:app`), while `:domain` (`Drill`), `:data` (`DrillDto`), and `:usecases` (`GetPracticeDrillsUseCase`) are kept untouched to preserve existing contracts and allow future reuse in chat dialogues.
  - *Pia Design System*: Theme tokens strictly match `docs/ui/basquet_pia_design_system.jpeg` (`#1D2E54` Primary, `#F15A24` Tactical Orange, `#F5F5F5` Background, `#FFFFFF` Surface, `#1A1A1A` Text, `#616161` Text Muted, `#2E7D32` Success, `#D32F2F` Danger).
  - *Match Detail Dialog*: Omitted per explicit user decision. The 14-match table already displays all 16 statistical columns directly.
  - *"Explorar al Xat" Action*: Navigates to `Destination.Chat` pre-populating the chat input field with the insight's `exploreChatPrompt`.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide an authentic, professional Tablet Landscape interface for the head coach of CE Escola Pia Sabadell Junior Masculí. The coach can navigate seamlessly via the Navy Navigation Rail between the **Dashboard** (season baseline, 4 KPI cards, per-round scoring evolution chart, 14-match table) and **Anàlisi** (actionable tactical strengths and improvement areas with rich metrics and one-click chat exploration), fully aligned with the Pia Design System.

### Non-Goals
* No live ViewModel-to-UseCase integration in this slice (reserved for `feature_007_dashboard_integration`). UI operates on rich, realistic preview data modeled with the updated domain entities.
* No portrait or smartphone layouts (strictly locked to `sensorLandscape`).
* No drills UI components (purged from presentation per user decision).
* No multi-thread chat or conversational AI implementation (reserved for `feature_006_chat_ui`).
* No `MatchDetailDialog` modal (omitted per user decision).

### Job Story
When a basketball coach reviews Phase 1 performance on a landscape tablet,
I want to view the consolidated Dashboard (KPIs, round-by-round chart, match box scores) and the Anàlisi grid (strengths and prioritized improvement areas with exact metric evidence),
so I can diagnose why we went 3-11 and tap "Explorar al Xat" to plan tactical corrections for Phase 2.

### Acceptance Scenarios

#### Scenario 1: Navigation Shell Rendering & Tab Switching
* **Given** a tablet device in landscape orientation (1280x800dp)
* **When** BasketCoach is launched
* **Then** the Navy Navigation Rail (80dp, `#1D2E54`) is rendered on the left with Dashboard, Anàlisi, and Chat items
* **And** the White Top Bar (64dp, `#FFFFFF`) renders the BasketCoach brand, the "Junior Masculí Interterritorial" chip, the green "Dades consolidades · 14 partits 1a Fase" badge, and the coach profile (Coach Jordi avatar, "Head Coach")
* **And** tapping "Dashboard" displays the Dashboard screen, while tapping "Anàlisi" displays the Anàlisi screen.

#### Scenario 2: Anàlisi Screen — Hero Card & Filter Segmented Control
* **Given** the coach navigates to the "Anàlisi" screen
* **When** the screen renders
* **Then** the Hero Card displays "LÍNIA BASE FASE 1 · DATASET.JSON VERIFICAT · 14/14 PARTITS" and headline "Balanç Competitiu: 3 Victòries - 11 Derrotes (21.4% de victòries)"
* **And** the filter control displays "Tots (5)", "Fortaleses (2)" with a green dot, and "Àrees de Millora (3)" with a tactical orange dot
* **When** tapping "Fortaleses", only the 2 tactical strength cards are visible
* **When** tapping "Àrees de Millora", only the 3 improvement area cards are visible
* **When** tapping "Tots", all 5 cards are visible.

#### Scenario 3: Anàlisi Screen — Card Anatomy per Insight Type
* **Given** the 3-column grid of insight cards
* **When** inspecting a Tactical Strength card (e.g. "Eficiència en Tir Interior")
* **Then** it displays a green "Fortalesa Tàctica" pill, context tag ("Fase Ofensiva · Pintura"), title, description, grey metric panel (`58.4% efectivitat`, `+8.2% sobre mitjana lliga`, `dataset:paint_eff`), and footer with green verified checkmark
* **When** inspecting an Improvement Area card (e.g. "Balanç Defensiu en Transició")
* **Then** it renders a tactical orange border (`#F15A24`/30), orange "Àrea de Millora" pill, priority tag ("Crítica #1"), grey metric panel (`16.2 pts/partit`, `1.31 pts/pos en transició rival`, `dataset:fastbreak_def`), footer warning note ("Pilar corrector Fase 2"), and a Navy button "Explorar al Xat".

#### Scenario 4: "Explorar al Xat" Navigation Action
* **Given** an improvement card with the "Explorar al Xat" button
* **When** the coach taps "Explorar al Xat"
* **Then** the application navigates to `Destination.Chat` with the insight's exploratory prompt pre-populated in the chat state.

#### Scenario 5: Dashboard Screen — 4 KPI Cards
* **Given** the coach navigates to the "Dashboard" screen
* **When** the KPI section is rendered
* **Then** 4 cards are displayed in a horizontal row:
  1. "Anotació Mitjana": `64.6` vs `73.7 ppg rival`, `-9.1 Diferencial net`, progress bar at 47%.
  2. "Rebots & Balanç": `22.8 reb/p`, orange vertical indicator on right, `Balanç negatiu (-7.8)`, `5.9 Ofensius` / `16.9 Defensius`.
  3. "Eficiència Tir (eFG%)": `40.5% global`, 3 columns (`2P 43.4%`, `3P 25.4%`, `TL 56.4%`), progress bar at 40.5%.
  4. "Control de Joc": `0.59 ràtio AST/TO`, `10.3 AST / p`, `17.6 Pèrdues`, `10.3 AST` / `17.6 TO`.

#### Scenario 6: Dashboard Screen — 14-Round Scoring Evolution Bar Chart
* **Given** the Bar Chart section on the Dashboard
* **When** rendered
* **Then** 14 pairs of bars (Pia vs Rival) are displayed for rounds J1 to J14
* **And** winning rounds J3, J9, and J10 highlight the Pia bar in Green (`#2E7D32`) with floating labels "W 71-68", "W 68-65", "W 67-65"
* **And** losing rounds display the Pia bar in Navy (`#1D2E54`) and Rival bar in Slate (`#CBD5E1`).

#### Scenario 7: Dashboard Screen — 14-Match Consolidated Table
* **Given** the match table section on the Dashboard
* **When** rendered
* **Then** all 14 rounds are listed with 16 columns (Jornada, Partit, Marcador, eFG%, 2P%, 3P%, TL%, REB O/D, AST, TO, AST/TO, ROB, TAP, PF, 2a Opció, C. Atac)
* **And** winning rows (J3, J9, J10) display green score pills and subtle green row background
* **And** losing rows display red score pills.
