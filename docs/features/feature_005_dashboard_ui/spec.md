* **Objective:** Implement the tablet landscape application shell (fixed 80dp Navy Navigation Rail + 64dp White Top Bar with Coach Jordi profile avatar) and the Phase 1 Dashboard screen displaying the baseline hero summary card (3V-11D, 21.4%), 4 KPI metric cards, a 14-round scoring evolution bar chart (with green win badges for J3, J9, J10), and the consolidated 14-match 16-column statistical table.

ViewModel and real UseCase integration are deferred to `feature_008_dashboard_integration`.

  4. *Language & Localization*: 100% localized in Catalan (`ca`) in `app/src/main/res/values/strings.xml`.
  5. *Pragmatic Testing*: Compose UI tests run headless on the JVM using Robolectric (`NavigationTest` and `DashboardScreenTest`) verifying real layout, semantics, and navigation switching.
* **Necessary Questions:** None — all requirements and architectural boundaries clarified and agreed upon.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide the head coach (Jordi) of CEB Escola Pia Sabadell (Junior Masculí Interterritorial) with a dedicated, high-density Tablet Landscape dashboard to review the consolidated 14-game Phase 1 competition baseline. The coach can navigate between sections via a fixed Navy Navigation Rail and inspect scoring evolution, key performance indicators (shooting, rebounding, game control), and complete per-match box scores.

### Non-Goals
* Dynamic data fetching or ViewModel integration via `GetPhase1GamesUseCase` (scheduled for `feature_008_dashboard_integration`).
* Domain/Data model expansion for tactical AI insights (scheduled for `feature_006_analysis_ui`).
* Interactive Match Detail modal popup dialog (`#match-modal` omitted per user decision).
* Phone or portrait layouts (strictly tablet landscape `1280x800dp`).
* Dynamic AI chat assistant thread (scheduled for `feature_007_chat_ui` and `feature_010_chat_integration`).

### Job Story
When Coach Jordi opens BasketCoach on his tablet during practice preparation,
I want to view the consolidated 14-game Phase 1 baseline balance, KPI averages, scoring chart, and full box-score table,
so I can quickly assess team strengths and systemic weaknesses to plan Phase 2 practices.

### Acceptance Scenarios

#### Scenario 1: Tablet Landscape Application Shell Rendering
* **Given** the app launches on an Android Tablet in Landscape orientation (`1280x800dp`).
* **When** the root `BasketCoachApp` composable is displayed.
* **Then** the coach sees:
  1. A fixed `80dp` Navy (`#1D2E54`) `BasketCoachNavRail` on the left displaying destinations: "Dashboard" (active), "Anàlisi" (inactive), and "Chat" (inactive).
  2. A fixed `64dp` White (`#FFFFFF`) `BasketCoachTopBar` with bottom border (`#D1D5DB`/30) displaying "BasketCoach" (bold Navy), the "Junior Masculí Interterritorial" pill, the green verified pill ("Dades consolidades · 14 partits 1a Fase"), and the circular Coach Jordi profile avatar (`36dp`) with labels "Head Coach" / "Jordi".
  3. The main content canvas displaying the Dashboard screen.

#### Scenario 2: Navigation Rail Destination Switching
* **Given** the coach is on the Dashboard screen.
* **When** the coach taps on the "Anàlisi" item in `BasketCoachNavRail`.
* **Then** the active rail container moves to "Anàlisi" and the main viewport displays the clean `PlaceholderScreen` for Anàlisi ("Pròximament a la Fase 2").
* **When** the coach taps on "Chat", the Chat placeholder screen is displayed.
* **When** the coach taps back on "Dashboard", the full Dashboard content is restored.

#### Scenario 3: Baseline Phase 1 Hero Card Display
* **Given** the coach is viewing the Dashboard screen.
* **When** inspecting the `DashboardHeroCard`.
* **Then** the coach sees:
  - Header badge: `"LÍNIA BASE FASE 1"` and `"dataset.json verificat · 14/14 partits"` with green check icon.
  - Headline: `"Balanç Competitiu: 3 Victòries - 11 Derrotes (3V - 11D)"`.
  - Subtitle: red pill `"21.4% victòries"`, `"Junior Masculí Interterritorial"`, and `"CEB Escola Pia Sabadell"`.
  - Right summary block: `"BALANÇ FASE 1 / 3 Victòries / 11 Derrotes"` and the square `"14 PARTITS"` badge.

#### Scenario 4: 4 Key Performance Indicator (KPI) Cards
* **Given** the coach is viewing the Dashboard screen.
* **When** inspecting `KpiCardRow`.
* **Then** exactly 4 cards are rendered horizontally in a row:
  1. *Anotació Mitjana*: `"64.6"` vs `"73.7 ppg rival"`, red badge `"-9.1 Diferencial net"`, `"14 partits"`, progress bar at 47% in red.
  2. *Rebots & Balanç*: vertical Tactical Orange accent bar (`6dp`) on right border, `"22.8"` `reb/p (vs 30.6)`, red badge `"Balanç negatiu (-7.8)"`, footer `"5.9 Ofensius"` / `"16.9 Defensius"`.
  3. *Eficiència Tir (eFG%)*: `"40.5%"` `global Fase 1`, 3 mini-boxes (`2P 43.4%`, `3P 25.4%`, `TL 56.4%`), progress bar at 40.5% in Navy.
  4. *Control de Joc*: `"0.59"` `ràtio AST/TO`, red badge `"10.3 AST / p"`, `"17.6 Pèrdues"`, footer `"10.3 AST"` / `"17.6 TO"`.

#### Scenario 5: 14-Round Scoring Evolution Bar Chart
* **Given** the coach scrolls to the evolution chart section.
* **When** inspecting the 14 competition rounds (`J1` to `J14`).
* **Then** winning rounds `J3` (71-68), `J9` (68-65), and `J10` (67-65) render the Pia Sabadell bar in Success Green (`#008C45`) with a floating `"W <score>"` badge and green bold X-axis labels (`J3 (V)`, `J9 (V)`, `J10 (V)`).
* **And** all 11 losing rounds render the Pia bar in Primary Navy (`#1D2E54`) and the Rival bar in Slate (`#CBD5E1`).
* **And** the legend shows: "Victòria Pia (W)" (green), "Pia Sabadell" (navy), "Rival" (slate).

#### Scenario 6: Consolidated 14-Match 16-Column Statistical Table
* **Given** the coach inspects the match table section.
* **When** viewing the consolidated games.
* **Then** all 14 Phase 1 matches (`J1` to `J14`) are rendered in order with 16 statistical columns (`JORNADA`, `PARTIT`, `MARCADOR`, `EFG%`, `2P%`, `3P%`, `TL%`, `REB (O/D)`, `AST`, `TO`, `AST/TO`, `ROB`, `TAP`, `PF`, `2A OPCIÓ`, `C. ATAC`).
* **And** winning rows (`J3`, `J9`, `J10`) display a subtle green row tint and green score badge (`#E8F5E9` bg, `#008C45` text); losing rows display a red score badge (`#FFEBEE` bg, `#D32F2F` text).
* **And** home/away perspective is formatted clearly with bold text for CEB Pia Sabadell.

#### Scenario 7: Omission of Match Inspector Modal
* **Given** the user's decision to omit the interactive Match Inspector modal dialog.
* **When** the coach views the 14-match table or chart.
* **Then** rows and bars are clean display elements without opening `#match-modal`.
