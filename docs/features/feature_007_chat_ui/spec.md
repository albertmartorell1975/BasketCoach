## 1. Source Feature & Idea Diagnosis
* **`id`:** `feature_007_chat_ui`
* **`area`:** `app`
* **`depends_on`:** `["feature_005_dashboard_ui"]`
* **`status`:** `in_progress`
* **`module_topology`:** `Layer-Based (:domain, :usecases, :data, :app)`
* **Objective:** Implement the high-density Tablet Landscape single-thread conversational AI assistant screen (`ChatScreen`) in `:app` matching the authoritative prototypes in `docs/ui/screens/chat_general/` and `docs/ui/screens/chat_detalle/`. The coach interacts with a continuous conversation thread, selects tactical reflection areas ("Àrees d'Intervenció · 1a Fase"), inspects deep diagnostic evidence and spatial court distributions, reviews AI Socratic inquiry and formative practice drill recommendations (Option A & Option B), selects drill choices directly in the thread, types custom tactical reflections, and seamlessly receives pre-grounded exploration prompts when navigating from the Analysis screen ("Explorar al Xat").
* **Identified Ambiguities / Assumptions:**
  1. *Unified Two-Pane Architecture (Harmonizing `chat_general` and `chat_detalle`)*: In `chat_general`, the left pane displays the 4 Intervention Area cards ("Tria un Fil de Treball"). In `chat_detalle`, the left pane displays the deep diagnostic evidence for the active priority area (14.8 pts 2nd chance, 13.2 defensive rebounds conceded, Zero-Assumption rule badge, and perimeter vs paint court spatial distribution). To satisfy both prototypes without fragmenting into multiple screens or violating Constraint #6 (Single Thread Chat), the Left Pane implements a seamless stateful mode switch:
     - `ChatLeftPaneMode.TOPIC_LIST`: Shows the 4 intervention area cards ("Tria un Fil de Treball").
     - `ChatLeftPaneMode.DIAGNOSTIC_EVIDENCE`: Shows the deep diagnostic context, box-score metric bar, and half-court spatial distribution canvas for the selected area, with a "← Tots els fils" navigation toggle to return to the topics list.
  2. *Single Continuous Thread Mandate (Constraint #6)*: The chat interface maintains a single continuous conversational stream. Selecting an intervention area or clicking a topic card filters or pre-grounds the ongoing dialogue rather than creating separate disjoint sessions or chat history backstacks.
  3. *Seamless Navigation Hand-off from Analysis Screen*: In `feature_006_analysis_ui`, `AnalysisScreen` triggers `onNavigateToChat(card.exploreChatPrompt)`. To support this without regressions, `ChatRoute` in `Destinations.kt` is modeled as `@Serializable data class ChatRoute(val initialPrompt: String = "")`. `BasketCoachAppState.navigateToChat(prompt: String = "")` passes the prompt, and `ChatScreen` pre-fills the input field and displays the relevant conversation context.
  4. *Strict Default-Free & Non-Nullable UI Models (Constraint #17)*: All presentation models in `ui.chat.model` (`ChatUiState`, `ChatMetaHeaderUiModel`, `ChatTopicCardUiModel`, `ChatDiagnosticEvidenceUiModel`, `ChatMessageUiModel`, `ChatDrillOptionUiModel`, `ChatSummaryCardUiModel`) declare **zero default parameter values** and **zero nullable fields**. The static provider `ChatPreviewData` provides complete, fail-fast authentic preview states. (ViewModel integration with `SendChatMessageUseCase` and the live DevExpert API is deferred to `feature_010_chat_integration`).
  5. *Minimum Font Size Mandate (Constraint #16)*: All UI typography across topic cards, metric pills, message timestamps, court diagram labels, drill cards, and input fields strictly enforces a minimum font size of `12.sp` (never `10.sp` or `11.sp`).
  6. *Decoupled Composable Architecture*: `ChatScreen` (stateful) manages local remembered interactions (input text, sending state, active topic, left pane mode, and appended messages from interactive drill selections), delegating rendering to `ChatContent` (stateless).
  7. *Bilingual Localization*: Full Catalan (`res/values/strings.xml`) and Spanish (`res/values-es/strings.xml`) parity for all headers, meta tags, topic badges, socratic messages, drill cards, buttons, and input placeholders.
  8. *Graphic Assets Policy*: Mockup screenshots remain in `docs/features/feature_007_chat_ui/ui/screens/` as reference guides (never converted to drawables). Avatars reuse `ic_avatar_coach.webp` and vector badges; court graphics are rendered via standard Jetpack Compose Canvas.
* **Necessary Questions:** None — all requirements clarified.

## 2. Goal, Non-Goals & Acceptance Scenarios

### Goal
Provide Coach Jordi with a high-density, tablet-optimized single-thread conversational AI workbench (`ChatScreen`) to translate Phase 1 competition findings (3V-11D) into concrete Phase 2 training microcycles. The coach can select tactical intervention areas, review empirical evidence and court spatial distribution, engage in Socratic dialogue with AI, compare and select formative drill recommendations (e.g. 3c3 Crash vs Box-Out), type free-form reflections, and arrive at integrated weekly practice commitments.

### Non-Goals
* Live OkHttp streaming or DevExpert API network calls (deferred to `feature_010_chat_integration`).
* Multi-thread session switching or persisted database history (strictly forbidden by Constraint #6).
* Smartphone or portrait orientations (strictly constrained to Tablet Landscape `1280x800dp`).
* Individual player statistical breakdowns (team-level metrics only per Constraint #5).

### Job Story
When Coach Jordi navigates to the Chat assistant on his tablet (either directly from the NavRail or via 'Explorar al Xat' from an Analysis card),
I want to review tactical intervention areas, empirical diagnostic evidence, and Socratic drill suggestions,
so I can select practice drills and refine weekly training microcycles for Phase 2.

### Acceptance Scenarios

#### Scenario 1: Tablet Landscape Chat Screen Rendering & Navigation
* **Given** the app is running on an Android Tablet in Landscape orientation (`1280x800dp`).
* **When** the coach taps the "Chat" item in `BasketCoachNavRail` (or navigates from Anàlisi).
* **Then** the active navigation rail indicator highlights Chat with a filled forum icon.
* **And** the viewport renders `ChatScreen` displaying:
  1. The Context Meta Header ("Espai de Reflexió Tàctica · 1a Fase", "Balanç: 3V - 11D", "Junior A Masculí").
  2. The Left Workbench Pane (4 columns) displaying the Intervention Areas header ("Àrees d'Intervenció · 1a Fase", "Tria un Fil de Treball") with 4 topic cards and the Socratic Pia methodology note.
  3. The Right Workbench Pane (8 columns) displaying the assistant header ("Assistent Socràtic BasketCoach", "Connexió Assistent Activa", "Línia Base: 14 Partits Consolidats"), the conversational stream (or welcome state), and the bottom input bar.

#### Scenario 2: Intervention Area Selection & Left Pane Mode Switching
* **Given** the coach is viewing the Chat screen with the Topic List active in the Left Pane.
* **When** the coach clicks Topic Card #1 ("Control del Rebot Defensiu").
* **Then** Topic Card #1 becomes active with highlighted styling.
* **And** the Left Pane smoothly transitions to `ChatDiagnosticEvidenceView`, displaying:
  1. The Diagnostic Header Card ("Àrea de Millora #1 · Prioritària", "Control del Rebot Defensiu").
  2. The Evidence Metric Bar showing "14.8 pts/partit" (Punts 2a Oportunitat, +5.1 vs promig) and "13.2 reb/partit" (Rebots Ofensius Concedits, 3r pitjor).
  3. The Zero-Assumption Rule verification card.
  4. The Court Spatial Distribution visualizer with perimeter vs interior heat clusters (61% Exterior: 29% Ala Esquerra, 32% Capçalera, 23% Ala Dreta; 39% Interior: 16% Pintura).
  5. The Socratic methodology cycle reminder ("Evidència → Reflexió → Exercicis → Compromís").
  6. A "← Tots els fils" toggle button allowing the coach to switch back to the Topic List.

#### Scenario 3: Conversational Stream & Message Bubble Anatomy
* **Given** the conversation stream is displayed in the Right Pane.
* **Then** the messages follow strict visual hierarchy:
  1. **AI Assistant Bubbles (Left-aligned)**:
     - Assistant avatar badge ("P" with tactical dot).
     - Sender name "BasketCoach", timestamp, and evidence tag (e.g. "Evidència Traçable", "Corroborat per Dades", "Focus Integrat").
     - Light gray rounded container (`PiaSurfaceContainerLow`) with top-left square corner and body text.
     - Optional Socratic question callout box with `contact_support` icon and bold tactical question.
  2. **Coach Message Bubbles (Right-aligned)**:
     - Timestamp, sender name "Coach Jordi", and "Entrenador Principal" tag.
     - Pia Navy container (`#1D2E54`) with top-right square corner and white text.
     - Coach avatar badge.

#### Scenario 4: Formative Practice Drill Recommendation Cards & Interactive Selection
* **Given** an AI message contains formative drill recommendations.
* **Then** two option cards are rendered side-by-side in a responsive grid:
  - **Opció A**: "3c3 Crash vs Box-Out" (Intensitat Alta badge, tactical description, "Seleccionar Opció A" button).
  - **Opció B**: "Regla Primer Contacte 4c4" (Continuïtat badge, tactical description, "Seleccionar Opció B" button).
* **When** the coach taps "Seleccionar Opció A".
* **Then** a coach confirmation message ("Comencem amb l'Opció A (3c3 Crash vs Box-Out) els dimecres...") is appended to the conversational stream.
* **And** the assistant responds with the Integrated Focus summary card ("Capacitat de Tancar el Rebot Defensiu", Objectiu: < 9.5 pts 2a oportunitat, Microcicle: 4 setmanes).

#### Scenario 5: Free-Form Text Input & Message Dispatch
* **Given** the coach types a custom reflection or tactical query into the bottom input field.
* **When** the coach taps the Send button (or submits via keyboard IME Action).
* **Then** a new coach message bubble containing the typed text is appended to the conversation stream.
* **And** the input field is cleared and auto-scrolled to the bottom of the stream.

#### Scenario 6: Hand-Off from Analysis Screen ('Explorar al Xat')
* **Given** the coach is on the Analysis screen and taps "Explorar al Xat" on an improvement card (e.g. "Rebot Defensiu").
* **When** the app navigates to `ChatRoute(initialPrompt = "...")`.
* **Then** `ChatScreen` receives the initial exploration prompt.
* **And** the input field is pre-filled with the prompt (or automatically dispatched) and Topic #1 ("Control del Rebot Defensiu") is selected with its diagnostic evidence active.

#### Scenario 7: Bilingual Support Verification (Catalan & Spanish)
* **Given** the device locale is set to Spanish (`es_ES` or `es`).
* **When** the coach opens the Chat screen.
* **Then** all UI elements display Spanish strings from `res/values-es/strings.xml` ("Espacio de Reflexión Táctica", "Elige un Hilo de Trabajo", "Asistente Socrático BasketCoach", "Seleccionar Opción A", etc.).
* **When** the locale is set to Catalan (`ca_ES` or `ca`), all strings display in Catalan from `res/values/strings.xml`.
