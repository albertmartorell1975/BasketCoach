# build-brief Specialist

This skill provides a guided briefing process for new software projects or features.

## Core Rules
* **One Question at a Time**: Interview the user one question at a time.
* **No Code First**: Do not implement code until discovery is complete.
* **Controlled Outputs**: Create `CONTEXT.md`, `docs/build-brief.md`, `docs/domain-model.md`, and `docs/risks-and-open-questions.md`.

## Workflow
1. Establish Discovery Frame.
2. Build Shared Language (Glossary).
3. Discover Users and Access.
4. Discover Workflows and Domain State.
5. Discover Technology and Constraints.
6. Define MVP Scope.
7. Discover Design Direction.
8. Record Decisions (ADRs).
9. Discovery Quality Gate.
